# 关键决策记录

按时间倒序记录「做了什么决定 + 为什么」，方便以后回溯。

## 2026-11-09

- **组共享 API 配置存元数据、密钥单独加密**：`groups.ai_config` 只保存渠道、模型和 `apiKeyConfigured` 等元数据，渠道 Key 继续加密存放在 `group_channel_secrets`，统一由 `channel-secrets` Edge Function 读写；组长写、成员读，避免成员直接改库或明文落库。
- **组邀请码由组长创建时填写**：邀请码等价于「组名 + 密码」，创建组时由组长自行设置（至少 8 位），不再由系统生成后只展示一次；申请加入只需搜索组名并输入邀请码，不需要账号密码。
- **成员画布改为只读读取云端状态**：取消手动发布与 `group_canvases` 快照表，组员点击成员直接读取对方 `user_state` 中自动同步的画布数据，并通过组内存储策略读取对方 `user-data` 目录下的画布图片；同组成员可只读浏览，非同组不可访问。
- **组配置优先于个人配置**：存在当前组共享配置时，图片、视频、文本生成优先使用组渠道和密钥；本地代理、重新生成行为和自动居中仍以个人设置为准。

## 2026-11-06

- **移除音频节点/音频生成及 3D 全景插件**：按产品范围删除画布音频节点、独立音频生成能力与 Agent 工具，以及官方全景插件；保留视频生成声音设置和视频接口参数。历史 changelog 保持不变，当前版本变更记录在 Unreleased。

## 2026-11-05

- **修复 `启动画布.bat` 双击无反应**：原因是脚本用了 LF 换行符 + UTF-8，Windows cmd 解析错乱（日志出现「不是内部或外部命令」）。改为 CRLF + GBK 编码（去掉 chcp 65001），实测构建 + 启动正常、3000 端口成功监听。
- **确认无需 Python 虚拟环境**：项目是纯 JS/TS 项目，运行时只有 bun。
- **确认无需 Docker**：本机未安装 Docker（仅下载了安装包，`C:\Program Files\Docker\` 不存在）；启动脚本走 bun，不依赖 docker。

## 2026-11-04

- **fork basketikun/infinite-canvas 并本地化**：改品牌名为「蝶讯 AI-D.SD」，本地克隆到 `C:\Users\LINZHANPENG\Documents\默认项目\infinite-canvas`，自己的仓库为 `DSD-AI`。
- **选用 bun 而非 docker 运行**：本地 docker 不可用；且官方 docker 镜像不含蝶讯定制界面，要跑定制版得走 `docker-compose.local.yml` 自行构建，成本高于直接用 bun。
