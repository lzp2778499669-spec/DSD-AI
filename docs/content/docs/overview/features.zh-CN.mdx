# 功能介绍

本文档记录当前项目已经实现的主要功能。

## 账号与安全

- 基于 Supabase 的账号体系：注册、登录、会话管理由 `supabase.auth` 提供，注册时只需账号名和密码，系统自动生成仅供认证使用的内部邮箱。
- 新注册用户默认为「待审核」状态，登录后只能看到审核等待提示；管理员在配置页「用户审核」中把状态改为 `approved` 后才能进入画布、提示词库、我的资产和配置等受保护页面，改为 `disabled` 后会被退出并阻止访问。
- 支持忘记密码：用户提交找回申请后窗口强制锁定，管理员确认时旧密码立即失效且其他设备会话被退出，用户设置新密码后才能重新登录；管理员拒绝则回到登录界面。
- AI 渠道的 API Key 加密保存在 Supabase（由 `channel-secrets` Edge Function 读写），浏览器本地只保存「已配置密钥」的状态标记，明文 Key 不落浏览器存储。
- 画布项目、我的素材、生成偏好和渠道配置随登录账号同步到 Supabase（`user_state`），画布图片等文件保存在 Supabase Storage 的用户专属目录中，跨设备登录后可继续使用。

## 画布项目

- 支持创建多个画布项目。
- 支持项目重命名、删除、批量选择和批量删除。
- 支持单个画布项目导出为 JSON，也支持从 JSON 导入画布。
- 画布项目随登录账号自动同步到服务端，另可配置 WebDAV 作为额外的导出同步渠道。

## 无限画布

- 支持拖动画布、滚轮缩放、缩放滑杆和重置视图。
- 支持小地图定位，可开关小地图。
- 支持点阵、网格线、空白三种背景。
- 支持浅色和深色主题。
- 支持框选、多选、全选、取消选择、删除选中。
- 支持复制粘贴节点和节点之间的连线。
- 支持撤销和重做节点、连线、视口、背景和助手会话变化。
- 支持节点连线，并高亮当前节点相关的上下游节点和连线。
- 支持快捷键帮助，覆盖缩放、框选、全选、复制粘贴、撤销重做、删除、退出选择和拖入图片。

## 节点

目前画布中有五类节点：

- 图片节点：展示上传图片、生成图片或我的素材图片。
- 文本节点：保存提示词、说明文案、AI 文字回答等文本内容。
- 视频节点：保存生成视频并使用原生播放器预览，支持截取首帧、末帧或当前帧为图片节点。
- 生成配置节点：汇总上游文本、图片、视频和组，统一配置模型、比例、数量后批量生成图片、视频或文本。
- 组节点：把多个节点收纳为一组，可作为整体连线，把组内全部资源一次性引用给生成配置。

节点支持：

- 拖拽移动。
- 四角缩放。
- 图片节点等比缩放或自由比例切换。
- 查看节点基础信息和 JSON。
- 删除、复制、粘贴。
- 通过左右连接点建立上下游关系。

## 图片工作流

- 支持上传图片到新节点。
- 支持拖拽图片文件到画布。
- 支持替换已有图片节点内容。
- 支持下载图片节点。
- 支持把图片节点保存到“我的素材”。
- 支持图片裁剪和本地蒙版局部重绘，并把结果生成为新的图片节点。
- 支持本地多角度变换，并把结果生成为新的图片节点。
- 支持生成失败后重试。
- 批量生成多张图片时会先展示为图片组节点，支持叠卡预览、展开查看全部结果、设置主图和单张下载。

## AI 生成

AI 请求由浏览器前端直连用户配置的接口，可选开启本地转发代理。接口格式支持三种：

- OpenAI 格式：图像走 `/v1/images/generations`、`/v1/images/edits`，文本走 `/v1/responses`，模型列表走 `/v1/models`。
- OpenAI Chat 格式：文本走 `/v1/chat/completions`。
- Gemini 格式：图像和文本走 `models/{model}:generateContent`，视频走 `models/{model}:predictLongRunning` 并支持任务轮询与恢复。

视频能力同时支持两类接口：

- OpenAI 风格视频：`POST /v1/videos`、`GET /v1/videos/{id}`、`GET /v1/videos/{id}/content`，支持首末帧和通用参考图两种模式。
- Gemini 格式视频：`predictLongRunning` 提交任务后轮询结果。

Base URL 如果已经以 `/v1` 或 `/v1beta` 结尾，系统不会再重复追加。

可配置项：

- 多渠道 Base URL、API Key 和默认模型。
- 图片质量、分辨率（1K / 2K / 4K / 自动）、比例和生成数量。
- 视频模型、比例、清晰度、时长、生成声音和水印。
- 自定义生图 / 视频 / 文本接口的调用脚本，灵活适配不同中转站与自建服务。
- 本地转发代理：配置页提供独立开关，开启后 AI 请求经本机 `npx @basketikun/canvas-proxy@latest` 启动的代理转发，解决浏览器直连的 CORS 限制，默认地址 `http://127.0.0.1:23210`。

普通图片/文本节点可以直接输入提示词生成结果。生成配置节点可以读取上游节点内容，并按节点自己的配置批量生成多个图片、视频或文本结果。生成配置节点支持预览当前提示词和参考图输入，并调整输入顺序。

节点下方对话框和组装提示词输入框都支持 `@` 引用已连接的图片、文本、视频、组等资源；`@` 引用图片时，输入框内会直接显示该图片的真实缩略图，发送时会按当前连接自动编号交给模型理解。

如果存在当前组共享的 API 配置，图片、视频和文本生成会优先使用组渠道和密钥，组未配置渠道时回退个人配置。

## 组功能

- 组长创建组并自行设置组名和至少 8 位的邀请码，其他用户搜索组名并输入邀请码提交申请，组长审批通过后加入。
- 组长可以移除普通成员，重复申请会得到明确提示而不是数据库报错。
- 成员可以只读浏览组内其他成员的画布：平移查看、点击看大图、下载图片、查看完整提示词并存入我的素材，但不能编辑。
- 组长可以配置组共享 API 渠道和密钥并设置默认模型，成员只读使用。

## 画布助手

画布右侧助手面板支持：

- 文本问答。
- 生图。
- 读取当前选中节点作为引用。
- 自动把选中节点的上游节点也纳入引用。
- 粘贴图片到助手输入框并插入画布。
- 历史会话。
- 删除单条或多条会话。
- 重试回答。
- 把助手生成的文本插入画布。
- 把助手生成的图片插入画布。
- 折叠和展开助手面板。

## 节点插件系统

画布支持通过节点插件扩展新的节点类型，内置节点之外的能力都可以以插件形式加载：

- 支持通过 URL 动态安装、启用、更新和卸载远程节点插件。
- 提供官方插件注册表，节点插件面板可从项目仓库读取官方插件列表并一键安装。
- 提供 TypeScript 插件开发 SDK，可自行开发画布节点插件，并使用 AI 生成、面板控制等扩展能力。
- 内置 Markdown、SVG、HTML、便利贴等示例插件。
- 插件面板会显示插件版本，并对可升级的插件给出提醒。

Codex App 插件的安装与使用见 [Codex App 插件](/zh-CN/docs/overview/codex-app-plugin)。

## 提示词库

提示词数据保存在 Supabase `public.prompts` 公共表中，登录用户可浏览使用，管理员可在应用内管理：

- 按标题搜索，按分类和标签筛选。
- 查看提示词详情、封面和结果图。
- 复制提示词、把提示词加入“我的素材”、插入画布。
- 管理员可新增、编辑、删除提示词，选择或新建分类与标签，上传并裁剪封面（封面保存在 `prompt-covers` 存储桶）。

## 素材

“我的素材”支持：

- 新增文本素材和图片素材。
- 编辑素材标题、封面、标签、备注和内容。
- 删除素材。
- 按关键词搜索，按类型筛选。
- 分页浏览。
- 复制文本素材。
- 下载图片素材。
- 从提示词库和画布节点加入素材。
- 在画布中插入素材。

素材数据随登录账号同步到服务端。

## 配置

- 配置入口为独立的配置页，包含渠道、生成偏好、组、用户审核、本地存储、本地代理和 WebDAV 同程设置。
- 支持多个 OpenAI 兼容 / Gemini 格式渠道、默认模型、生成偏好和 WebDAV 同步设置。
- 第三方提示词、WebDAV 和 AI 接口都由浏览器前端直连，可选本地代理转发。

## 当前限制

- 画布更适合桌面端使用，移动端触控体验还未系统完善。
- AI 请求由浏览器直连用户配置的接口，自建部署时请确保只面向可信用户开放。
