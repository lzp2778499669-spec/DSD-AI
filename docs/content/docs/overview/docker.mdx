# Docker Deployment

## Use the published image

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

Open `http://localhost:3000`.

## Build locally

```bash
docker compose -f docker-compose.local.yml up -d --build
```

The application uses PocketBase for account registration and administrator approval. On first start, open `http://localhost:8090/_/` and create the PocketBase superuser. New registrations remain `pending` until an administrator changes `accessStatus` to `approved` in the `users` collection. The database persists in the `pocketbase_data` Docker volume; back it up before changing or removing volumes. The PocketBase host port is bound to loopback for local administration. Production deployments still need HTTPS and an access policy for the admin dashboard.

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

The app container serves the static Vite frontend. PocketBase stores user accounts in the persistent `pocketbase_data` volume; canvas projects, My Assets, generation history, and AI API keys remain in each user's browser by default. Prompt repositories are fetched directly by the frontend.

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: ghcr.io/basketikun/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
