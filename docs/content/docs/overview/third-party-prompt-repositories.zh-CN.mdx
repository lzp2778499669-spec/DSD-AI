# 提示词来源

提示词库的数据来自两部分：

## Supabase 公共提示词表

提示词主来源是 Supabase 的 `public.prompts` 表，由迁移 `202611100001_managed_prompts.sql` 和 `202611100002_prompt_admin.sql` 建立。登录用户可以浏览、搜索、按分类和标签筛选、复制提示词并加入素材或画布。

管理员在提示词库页可以直接管理：

- 新增、编辑、删除提示词。
- 选择已有分类 / 标签，或输入新值；删除分类或标签会从所有提示词中移除对应值。
- 上传并裁剪封面，封面保存在 `prompt-covers` 存储桶并通过公开 URL 显示。

## 历史来源

项目早期内置的 7 个第三方来源（来自 [Image Prompts](https://github.com/yukkcat/image-prompts) 等仓库）和自定义标准 JSON 来源功能均已移除，提示词库现在只读取 Supabase 公共表。
