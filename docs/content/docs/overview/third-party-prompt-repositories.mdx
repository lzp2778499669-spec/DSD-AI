# Prompt Sources

Prompt library data comes from two parts:

## Supabase managed prompts

The primary source is the Supabase `public.prompts` table, created by migrations `202611100001_managed_prompts.sql` and `202611100002_prompt_admin.sql`. Signed-in users can browse, search, filter by category and tag, copy prompts, and add them to assets or the canvas.

Administrators manage prompts directly in the prompt library page:

- Create, edit, and delete prompts.
- Pick existing categories/tags or enter new ones; deleting a category or tag removes it from all prompts.
- Upload and crop covers; covers are stored in the `prompt-covers` bucket and served via public URLs.

## Historical sources

The seven third-party sources originally built into the application (from the [Image Prompts](https://github.com/yukkcat/image-prompts) registry and related repositories) and the custom standard JSON source feature have both been removed; the prompt library now reads only from the Supabase managed table.
